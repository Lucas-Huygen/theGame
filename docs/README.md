# /docs — KaaiSpots project documentatie

Alles wat geen code is leeft hier. GitHub rendert markdown direct, dus je hoeft niets te installeren of te importeren.

## Structuur

| Pagina | Waarvoor |
|---|---|
| [`00 — Hub.md`](00%20—%20Hub.md) | Overzicht + snelle links |
| [`01 — Tasks.md`](01%20—%20Tasks.md) | Backup van takenlijst (live tracking gebeurt in **GitHub Issues + Project Board**) |
| [`02 — Tool-vergelijkingen.md`](02%20—%20Tool-vergelijkingen.md) | Index van alle tool-tests |
| `Claude vs ChatGPT.md`, `Make.com vs n8n.md`, `Plausible vs localStorage logger.md`, `Tally vs Google Forms.md`, `Claude Code vs Cursor.md` | Eén per vergelijking — vul in tijdens het experimenteren |
| [`03 — Wekelijks logboek.md`](03%20—%20Wekelijks%20logboek.md) | Wekelijks per persoon: gedaan / blocker / volgende week |
| [`04 — Vibe-coding chats.md`](04%20—%20Vibe-coding%20chats.md) | Index van AI-chat-bewijs. Plaats exports in `vibe-coding/` |
| [`05 — Reflecties.md`](05%20—%20Reflecties.md) | Reflectie-instructies + 3 individuele pagina's |
| `Reflectie — Lucas.md`, `Reflectie — Milan.md`, `Reflectie — Zeno.md` | Eigen reflectie per persoon |
| [`06 — Definition of Done.md`](06%20—%20Definition%20of%20Done.md) | Eigen DoD (vooraf invullen) |
| [`07 — Score-argumentatie.md`](07%20—%20Score-argumentatie.md) | Per rubric-criterium verwachte score + bewijs |

## Werkwijze

- **Tasks live tracken** → GitHub Issues + het Project Board (niet de checkboxes hier)
- **Docs schrijven** → bewerk de `.md` rechtstreeks op github.com (potlood-icoon) of lokaal
- **Wekelijks logboek** → één pull request per week, of gewoon committen op `main`
- **Vibe-coding chats** → drop ze als `.md` of screenshot in `vibe-coding/` en link ze in `04 — Vibe-coding chats.md`
- **Voor de docent** → één link: deze GitHub-repo
