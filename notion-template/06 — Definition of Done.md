# 06 — Definition of Done

> De cursus vraagt: *"Je beargumenteert zelf aan de hand van je eigen Definition of Done en de rubriek je verwachte score."* Schrijf dit **vooraf**, niet achteraf — anders is het niet eerlijk.

## Onze DoD voor "klaar"

### Site
- [ ] Live op een publieke URL met HTTPS
- [ ] Werkt op desktop én mobiel (getest op minstens 2 browsers + 2 devices)
- [ ] Lighthouse: Performance ≥ 85, Accessibility ≥ 90
- [ ] Alle filters werken écht (niet mock)
- [ ] 12 spots, allemaal met kloppende data

### Data-deel
- [ ] Visitor-data wordt anoniem gecaptured (cookie-conform)
- [ ] Suggesties via een form vloeien automatisch door een no-code flow
- [ ] Visualisatie zichtbaar voor team én jury

### Marketing
- [ ] Minstens 3 verschillende media-vormen (bv. video, poster, social post)
- [ ] Live social-account met minimum 5 posts
- [ ] Pitch deck + demo-video opgenomen

### Proces
- [ ] Notion is actief gebruikt (commit-frequentie zichtbaar in logboek)
- [ ] Elk teamlid heeft minstens 1 tool-vergelijking gedocumenteerd
- [ ] Vibe-coding chats verzameld
- [ ] 3 individuele reflecties geschreven

### Vibe-coding
- [ ] Alle code die door AI is geschreven heeft een chat-bewijs
- [ ] Minstens 2 AI-tools getest en vergeleken
